# مشوارك — Android | Clean Source V245.4

هذه نسخة نظيفة من **آخر إصدار V245.4**. تم حذف الملفات القديمة والمكررة فقط، **بدون تعديل أي حرف في الملفات التشغيلية المحتفظ بها**.

## التعديلات المحفوظة

- زر المساعدة: الشخصية الشفافة على قاعدة نبيتي كما في الصورة المعتمدة.
- موضع المساعدة: يمين مع واجهة الجهاز العربية، ويسار مع الإنجليزية (حسب لغة الجهاز، وليس قياسًا مباشرًا لعلامة Google Sites).
- معالجة WebView بعد العودة من الخلفية بما فيها حماية `PixelCopy` للإصدارات الأقل من API 26.
- كل ملفات Android وGradle وFirebase والخرائط والـWorkflow اللازمة للتطبيق محفوظة.

## ملفات مهمة

- `app/src/main/java/com/jekonix/mashwarak/MainActivity.kt` — الشاشة الرئيسية والمساعد وWebView.
- `app/build.gradle.kts` — إعدادات Gradle ونوعي APK `direct` و`play`.
- `.github/workflows/` — بناء Debug، Release، وإظهار البصمات.
- `mashwarak-config.properties` — إعدادات الربط الحالية؛ لم تتغير.
- `app/src/main/res/drawable-nodpi/mashwarak_support_avatar.png` — صورة المساعد التي يستخدمها الإصدار الحالي.

## تركيب النسخة على GitHub

**إذا أردت تطبيق آخر إصلاح فقط:** افتح المستودع داخل `app/src/main/java/com/jekonix/mashwarak/` واستبدل `MainActivity.kt` وحده بالملف المنفصل المرفق. لا ترفع ZIP كملف على GitHub.

**إذا أردت تنظيف المستودع نفسه من الملفات القديمة:**

1. استخدم GitHub Desktop وسجّل دخول حساب GitHub الخاص بالمستودع (لا علاقة له بربط حساب ChatGPT).
2. `File → Clone repository` ثم اختر `eosman0001-cyber/mashwarak-android`.
3. خذ نسخة احتياطية من المجلد المحلي خارج المستودع.
4. انسخ **محتويات** هذا ZIP إلى المجلد المحلي للمستودع، مع استبدال الملفات الموجودة. لا تنسخ مجلدًا إضافيًا حولها.
5. احذف من المجلد المحلي الملفات التاريخية التي في قائمة الحذف أدناه (BACKUP / ROLLBACK / WEB_UPDATE / Readmes القديمة ونسخ .txt المكررة). لا تحذف مجلد `.git` المخفي.
6. راجع تغييرات GitHub Desktop، ثم Commit وPush إلى `main`.
7. افتح Actions وتحقق من نجاح `Build Mashwarak APK` قبل الاعتماد على النسخة.

**تنبيه:** مجرد رفع ZIP نظيف أو رفع ملفات نظيفة على موقع GitHub **لا يحذف** الملفات القديمة التي كانت موجودة بالفعل في المستودع.

## ملاحظات

- لم يتم تنفيذ Android/Gradle build داخل بيئة إعداد الحزمة؛ لم تُختبر النسخة على الهاتف.
- هذه الحزمة خاصة بAndroid فقط. ملفات `Code.gs` و`Index` و`AdminV2` الخاصة بخدمة Apps Script لم تُعدَّل، ونسخ `WEB_UPDATE` المؤرشفة ليست ضمن مصدر Android المباشر.
- لا تنشئ مستودعًا جديدًا بدل الحالي لمجرد التنظيف، حتى لا تفقد إعدادات Secrets وWorkflows وReleases.
